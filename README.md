# Jackboy Dev Control

Build a new private-first web application named Jackboy, an AI-assisted developer and operations dashboard in the OMNI ecosystem. Visual identity: midnight BLACK background, metallic SILVER dominant for panels/text/borders, subtle ELECTRIC BLUE accent for active functions; emerald green for verified success and restrained crimson for errors. Use HEXAGONAL motifs subtly, responsive for iPhone/iPad/desktop. Core product: a SIMPLE HYBRID dashboard preserving a user's familiar layout, with explicit Classic View / Jackboy Assist toggle, opt-in contextual guidance, code inspection and diagnostics workspace, status indications, adaptive suggestions based on opted-in use without moving anything without permission, clear logs and approvals for changes. Build honest functional UI, real local/demo data clearly labeled; never claim live code access or actual fixes without integrations and verified results. Provide private owner login/invite flows where supported, safe read-only by default, security boundaries and a clear integration setup page for future GitHub/VS Code/OMNI/Honeycomb Terminal, no hardcoded credentials. Do not modify Honeycomb Terminal project. Make accessible responsive polished app and test navigation, states, and basic flows. This is the initial Jackboy foundation; report any missing integrations or prerequisites.
